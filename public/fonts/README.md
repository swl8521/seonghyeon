# Font assets

- Pretendard Regular: https://github.com/orioncactus/pretendard (SIL OFL 1.1). See Pretendard-LICENSE.txt. The UI uses the smaller regular font rather than preloading the full variable family. Bold is synthesized by the browser.
- Maru Buri Regular: https://hangeul.naver.com/font . Downloaded from NAVER's official hangeul.pstatic.net webfont distribution. See MaruBuri-LICENSE.html for the official copyright notice and full license snapshot.
- Both fonts are self-hosted without modification. Do not sell font files separately.
- Noto Serif KR remains managed by next/font/google for Chinese original text and fallback glyphs.

The webpage uses Maru Buri for literary text and Pretendard for controls and explanations. Generated share images retain their existing font setup.
